# gr33nops.github.io

Forwards the old GrabLine website address to its new home.

GrabLine moved to the [GrabLine organization](https://github.com/GrabLine/GrabLine). Its
website is now <https://grabline.github.io/>. Links to
`https://gr33nops.github.io/GrabLine/...` are sent to the same page there,
including the `#section`, so older app versions and existing links keep working.
The redirect removes the old `/GrabLine` prefix and goes directly to the root
site, preserving queries and fragments without an intermediate project URL.

Keep this repository: deleting it breaks those old links.
